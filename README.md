# 🎓 Math Exam Trainer (FastAPI + GigaChat)

**Что делает приложение:** 
Это веб-тренажер для подготовки к экзамену по дискретной математике и математическому анализу. Приложение генерирует случайные тестовые задачи с 4 вариантами ответов на основе базы знаний курса (файл `syllabus.md`). 
**Для кого:** Для студентов магистратуры, которым нужно быстро и интерактивно проверить свои знания перед экзаменом.

> **О GigaChat:** В проекте используется GigaChat API (языковая модель от Сбера) для интеллектуальной генерации условий задач строго по заданным темам.

## 🚀 Быстрый старт (Локальный запуск)

### 1. Создание окружения и установка зависимостей

Убедитесь, что у вас установлен Python 3.10+.

```bash
# Создаем виртуальное окружение
python -m venv venv

# Активируем его (Windows)
venv\Scripts\activate
# Активируем его (macOS/Linux)
source venv/bin/activate

# Устанавливаем основные и dev-зависимости
pip install -r requirements.txt
pip install -r requirements-dev.txt
```

### 2. Настройка переменных окружения

Создайте файл .env в корне проекта (рядом с app.py) на основе примера .env.example.

Вам потребуется ключ авторизации от GigaChat:

GIGACHAT_AUTH_KEY=ваш_ключ_авторизации_Base64
GIGACHAT_SCOPE=GIGACHAT_API_PERS

### 3. Запуск приложения (режим разработки)

uvicorn app:app --reload

После запуска откройте в браузере:

Сам сайт (одностраничник): http://localhost:8000

Документация Swagger UI: http://localhost:8000/docs

### 4. Запуск для обычной работы (Production)

Для запуска без авто-перезагрузки (без флага --reload), как это делается на сервере, используйте:

uvicorn app:app --host 0.0.0.0 --port 8000


### Тестирование

В проекте настроены автоматические тесты (проверка маршрутов и мок-тестирование ИИ).
Запуск локально:

python -m pytest -v

### Диагностика и Логи

Проверка работоспособности
GET /health — Возвращает {"status": "ok"}, если сервис работает.

GET /version — Возвращает текущую версию приложения (например, {"version": "1.0.0"}).

### Где смотреть логи

Все основные события выводятся в стандартный поток вывода (консоль/терминал), где запущен uvicorn.
При деплое на облачные платформы (FastAPI Cloud, Render и т.д.) логи доступны в панели управления сервисом.
